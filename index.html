One video. Every platform.
Published from one place.

WavePublish is a desktop application for publishing short-form video. The operator selects a clip, writes one caption, and the app delivers it to each connected platform using that platform's official API — to the operator's own accounts, and to no others.

See how it works →

What the application does

Publishing the same short video by hand to five platforms means five uploads, five captions and five sets of formatting rules. The application does that work in one pass.

📤

Publish once

Select a video, write the caption, choose the destinations. The app uploads to each connected platform using that platform's official API.

✍️

Per-platform captions

Every platform has different character and hashtag limits. Captions are adapted automatically for each one, without cutting words in half.

🖼️

Covers & formatting

Pick a thumbnail frame or upload a custom cover. Video can be converted to a vertical 9:16 format when a platform expects it.

🕒

Scheduling

Queue a post for a later time. A background worker publishes it at the scheduled moment and reports the result.

📊

Results in one view

Every publish is logged with its links and status, so a single failed platform can be retried without repeating the whole post.

🔒

Local & private

The app runs on the operator's own Mac. Videos and access tokens stay on that machine — there is no company server holding them.

Multiple brands, one tool

The application supports more than one content brand. Each brand keeps its own separate set of connected accounts and access credentials, and a publish is always sent to the accounts of the brand selected for that post. Credentials are never shared between brands.

Connected platforms

Each integration uses the platform's official publishing API and posts only to the operator's own brand accounts.

How TikTok is used

The application uses the TikTok Content Posting API for a single, narrow purpose: to upload the operator's own short-form videos to the operator's own TikTok account, started manually by the account owner inside the desktop app. The application does not read, collect or publish other users' content, and it is not offered to third parties.
