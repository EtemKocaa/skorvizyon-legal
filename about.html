About

A football brand that got tired of uploading five times

Skor Vizyon produces short-form football content — match moments, refereeing decisions and analysis — for social platforms. The publishing tool documented on this site exists because posting the same clip by hand, five times a day, was taking longer than making it.

The brand

Skor Vizyon is an independent football content project based in Türkiye. It is run by a single operator who films, edits and publishes the content. The accounts are the brand's own; the application publishes to those accounts and to no others.

The application

The publishing tool is a macOS desktop application written in Python. It was built for internal use by the brand rather than sold or distributed. It has no user accounts, no subscription and no server component — it runs on one machine, for one operator.

Scope

Publishing short-form video, plus the supporting work around it: captions, covers, scheduling and a record of what was posted where.

Not in scope

It does not browse, collect or repost other people's content, does not automate engagement, and does not act on any account it was not explicitly connected to.

Built with

Python and a native macOS interface, with ffmpeg for video handling and each platform's official API for publishing.

Why this site exists

Platforms that provide publishing APIs ask developers to document, publicly, what their application does and how it treats data. These pages are that documentation: what the tool is, how a post travels from a local file to a platform, and what happens to the data along the way.
