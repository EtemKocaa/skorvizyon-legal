About

Built because uploading the same clip five times took longer than making it

WavePublish is a macOS desktop application for publishing short-form video to several social platforms at once. It was written for the operator's own use, to remove the repetitive work of posting one clip by hand to five different places.

The application

WavePublish is a macOS desktop application written in Python. It was built for internal use rather than sold or distributed. It has no user accounts, no subscription and no server component — it runs on one machine, for one operator.

Scope

Publishing short-form video, plus the supporting work around it: captions, covers, scheduling and a record of what was posted where.

Not in scope

It does not browse, collect or repost other people's content, does not automate engagement, and does not act on any account it was not explicitly connected to.

Built with

Python and a native macOS interface, with ffmpeg for video handling and each platform's official API for publishing.

Who operates it

WavePublish is an independent software project operated by a single person in Türkiye. The same person writes the application and owns the social accounts it publishes to. There is no company, no team and no third-party user base.

Content brands

The application is used to publish for the operator's own content brands. Each brand has its own accounts and its own stored credentials inside the app, kept separate from one another. The application itself is brand-neutral: it is the publishing tool, not the content.

Why this site exists

Platforms that provide publishing APIs ask developers to document, publicly, what their application does and how it treats data. These pages are that documentation: what the tool is, how a post travels from a local file to a platform, and what happens to the data along the way.
